# WebRTC Audio Streaming

Stream lossless audio between yourself and one other person using peer-to-peer (WebRTC) technology.

https://rtc-audio.web.app/

## Features

- Peer-to-peer audio, no media server
- Codec choice: lossless FLAC or Opus (near-lossless, variable bitrate)
- Microphone or shared screen/tab audio, with input device selection
- Screen sharing with a stream viewer
- Live audio level meters and per-participant volume
- Chat with links, file attachments and drag-and-drop file sharing
- Shared live cursors
- Shareable 6-character room codes, invite link or manual join
- Connection stats
- Companion plugin to stream DAW audio directly, bypassing the OS audio stack (see [plugin](plugin/README.md))
